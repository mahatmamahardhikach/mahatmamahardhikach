# Featured Projects

## 🌟 ProgramingLive Ecosystem

### 1. HRIS - Human Resource Information System
**Repository**: [programinglive/hris](https://github.com/programinglive/hris)

An open-source HRIS system developed by the ProgramingLive community for managing human resources efficiently.

**Tech Stack**: TypeScript, JavaScript, React, Node.js, PostgreSQL

**Features**:
- Employee management
- Attendance tracking
- Leave management
- Payroll processing
- Performance reviews
- Document management

**Status**: 🟢 Active Development

### 2. Zettly - Productivity & Knowledge Management
**Repository**: [programinglive/zettly](https://github.com/programinglive/zettly)

A comprehensive productivity and knowledge management application that merges task management, idea linking, and priority planning into a single, flexible workspace.

**Tech Stack**: JavaScript, React, Node.js, MongoDB

**Key Features**:
- Task management with priority planning
- Idea linking and cross-referencing
- Note-taking capabilities
- Flexible workspace organization
- Collaboration tools
- Search and filtering

**Status**: 🟢 Active Development

---

### 3. Dev Workflow MCP Server

An MCP (Model Context Protocol) server designed to enforce development workflow discipline and improve team productivity.

**Tech Stack**: JavaScript, Node.js, MCP Protocol

**Features**:
- Workflow automation
- Task tracking
- Code review integration
- CI/CD pipeline management
- Team collaboration tools

**Status**: 🟢 Active Development

### 4. Laler - Laravel VarDumper Redirect
**Repository**: [programinglive/laler](https://github.com/programinglive/laler)

A Laravel package that captures VarDumper output and redirects it to any channel you control, improving the debugging experience.

**Tech Stack**: PHP, Laravel

**Features**:
- Capture debug output
- Flexible output channels
- Real-time debugging
- Integration with Laravel ecosystem
- Customizable formatting

**Status**: 🟢 Maintained

---

### 5. Committer - Commit Convention Tooling
**Repository**: [programinglive/committer](https://github.com/programinglive/committer)

Commit convention tooling for standardized-version releases. Ensures consistent commit messages and automated versioning.

**Tech Stack**: JavaScript, Node.js, npm

**Features**:
- Commit message validation
- Automatic versioning
- Changelog generation
- Release automation
- Integration with CI/CD

**Status**: 🟢 Active Development

---

### 6. Zettly Editor - WYSIWYG Editor
**Repository**: [programinglive/zettly-editor](https://github.com/programinglive/zettly-editor)

A Shadn-based WYSIWYG editor component for Zettly todo and notes applications, providing rich text editing capabilities.

**Tech Stack**: TypeScript, React, Shadn UI

**Features**:
- Rich text editing
- Markdown support
- Real-time preview
- Customizable toolbar
- Plugin system
- Accessibility support

**Status**: 🟢 Active Development
